# RAG Knowledge Assistant

An intelligent document question-answering application built using Retrieval-Augmented Generation (RAG).

## Project Goal

The application allows users to upload documents and ask questions about their contents.

## Planned Architecture

Documents → Chunking → Embeddings → Vector Database → Retrieval → LLM → Response

## Planned Technologies

- Python
- LangChain
- LangGraph
- FastAPI
- Streamlit
- ChromaDB
- Hugging Face
- LLM API
